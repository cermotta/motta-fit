# 🏋️‍♂️ MOTTA FIT — Personal Workout Assistant (AI Powered)

**MOTTA FIT** é um aplicativo web progressivo (PWA) de treino e musculação alimentado por Inteligência Artificial. O app coleta dados como idade, tempo de treino, disponibilidade de equipamentos e limitações físicas para gerar rotinas de treino 100% personalizadas.

---

## ⚡ Principais Funcionalidades

- 🧠 **Montagem de Treino com IA:** Gera planilhas de treino personalizadas com base na experiência, objetivos e equipamentos disponíveis.
- 🎬 **Animações SVG de Exercícios:** Visualização em tempo real do movimento dos exercícios (supino, agachamento, remada, rosca, etc.) para garantir a execução correta da postura.
- ⏱️ **Cronómetro de Descanso Automático:** Timer integrado com avisos sonoros e de vibração para controlar os intervalos entre séries.
- 📱 **Instalável no Telemóvel (PWA):** Pode ser adicionado à tela inicial do smartphone iOS ou Android para funcionar como um app nativo no ginásio.
- 💾 **Persistência Local:** Salva o perfil e o progresso do treino diretamente no dispositivo (`localStorage`).

---

## 🚀 Como Executar ou Instalar

### 1. Acesso Web & Instalação no Telemóvel
Acede à página do projeto via GitHub Pages:
`https://cermotta.github.io/motta-fit/`

- **No Android (Chrome):** Toca nos 3 pontos verticais no canto superior direito e seleciona **"Adicionar ao ecrã principal"**.
- **No iOS (Safari):** Toca no botão de **Partilhar** e seleciona **"Adicionar ao Ecrã Principal"**.

### 2. Execução Local
Basta clonar o repositório e abrir o ficheiro `index.html` em qualquer navegador:
